# Notion Blog 实现计划

> **给代理执行者：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法跟踪。

**目标：** 构建一个可部署到 Vercel 的 Next.js blog 首页，通过 `iframe` 嵌入公开 Notion 页面。

**架构：** 使用 Next.js App Router 创建单页应用。`app/layout.tsx` 提供全局元数据，`app/page.tsx` 渲染顶部栏和 Notion `iframe`，`app/globals.css` 控制全屏阅读布局。项目保持最小配置，让 Vercel 使用默认 Next.js 构建流程。

**技术栈：** Next.js、React、TypeScript、CSS、Vercel 默认构建。

---

- Create: `package.json`，定义依赖和 `dev`、`build`、`start`、`lint` 脚本。

```tsx
const notionBlogUrl =
  "https://tianlj.notion.site/LJTian-Blog-ce8a73f53641460cb4ba5f92596ae14b";

export default function Home() {
  return (
    <main className="site-shell">
      <header className="topbar">
        <a className="brand" href="/" aria-label="LJTian Blog home">
          LJTian Blog
        </a>
        <a
          className="notion-link"
          href={notionBlogUrl}
          target="_blank"
          rel="noreferrer"
        >
          Open in Notion
        </a>
      </header>
      <section className="embed-frame" aria-label="LJTian Notion blog">
        <iframe
          title="LJTian Blog on Notion"
          src={notionBlogUrl}
          loading="eager"
          referrerPolicy="no-referrer-when-downgrade"
          allowFullScreen
        />
      </section>
    </main>
  );
}
```
